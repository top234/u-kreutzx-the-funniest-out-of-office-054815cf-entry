A single-line out-of-office auto-reply, written to be the funniest one in the inbox: the sender is away until Monday, and so is the replacement who wrote the reply — the reader gets a chain of disappointment instead of help.

## Run it

```sh
node main.ts
```

This writes the one-line reply to `${OUTPUT_DIR:-/output}/entry.txt` (no trailing newline).
